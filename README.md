## THE WORLD IS NOT A NO BALL GAMES ZONE.

You know the sign.

Bolted to a council estate wall. Screwed onto a fence. Overlooking a concrete court. **NO BALL GAMES.**

Two words telling a generation where they couldn't play, create or take up space.

We took the warning and flipped it.

**NO BALL GAMES** is a British street-culture brand built from graffiti, football, estate life, music, original art and the refusal to stay inside somebody else's lines. The sign that said *don't* became the reason to make something.

From hand-painted jackets and one-of-one canvases to digital collectibles and dystopian storytelling, this is one idea moving across different worlds.

**THE SIGN IS OURS NOW. PLAY ANYWAY.**

## THREE WORLDS. ONE IDENTITY.

### 01 / GRIME ART — THE VISUAL LANGUAGE

Created by British contemporary artist **Charlie Buster**, Grime Art drags the energy of the street onto canvases, murals, clothing, sculptures and collectible objects.

Graffiti marks. Music culture. Layered paint. Typography. Pop icons. Fashion. Controlled chaos.

Not street art made polite for a gallery. The rawness stays.

## BUILT TO BE FOUND. BUILT TO WORK.

The site now includes a custom **NO PAGE GAMES** error page, article breadcrumbs, a reading-progress indicator, keyboard skip-navigation, reduced-motion support and a sitemap generated from the published pages.

**Every production build checks the actual rendered website**, including internal links, local assets, unique page titles, descriptions, canonical URLs and exactly one H1 per page. Broken links or missing SEO essentials stop the build instead of silently going live.

- `npm run check` — Astro and TypeScript diagnostics.
- `npm run build` — production build, website audit and sitemap generation.
- `npm run audit:site` — rerun the audit against an existing `dist/` directory.
- `public/robots.txt` — points search engines at [sitemap.xml](https://nbg1618.com/sitemap.xml) after deployment.
- `.github/workflows/validate.yml` — automatically validates pull requests.
- `.github/dependabot.yml` — checks npm packages and GitHub Actions for updates weekly.

The existing `.github/workflows/deploy.yml` handles publishing on pushes to `main`. A passing PR check is not the same as a successful production deployment.

## UNDER THE BONNET

This repository contains the NO BALL GAMES website, built with **[Astro](https://astro.build/)** and deployed to GitHub Pages at **[nbg1618.com](https://nbg1618.com/)**.

### Run locally

Use **Node.js 24** and npm to match GitHub Actions.

```bash
npm ci
npm run dev
```

Open **http://localhost:4321/**.

### Validate and build

```bash
npm run check
npm run build
npm run preview
```

The audited production build is generated in `dist/`, including `sitemap.xml`. Astro's site URL is `https://nbg1618.com` and its base path is `/`.

### Project layout

```text
src/
  layouts/               # Shared layout and long-form article template
  pages/                 # Home, About, Stories, Press, artist features and resource routes
  styles/site.css        # Global visual design
public/
  favicon.svg
  og/                    # Social preview artwork
  textures/              # Site textures
  robots.txt
  site.webmanifest
research/                # Source notes and rights/truth baselines
.github/workflows/       # Automation and deployment
```

Internal links use `import.meta.env.BASE_URL` where needed. Shared header and footer navigation live in `src/layouts/BaseLayout.astro`; navigation styling lives in `src/styles/site.css`. No secret environment variables are required for the basic static build. Do not commit `node_modules/`, `dist/` or `.astro/`.

## Reciprocal Graffiti Kings archive links

The NO BALL GAMES site links to its related, project-maintained [Graffiti Kings wiki](https://graffitikings.com/), with deeper sources for [Charlie Buster’s Grime Art artwork](https://graffitikings.com/pages/charlie-buster-grime-art-history.html), [NO BALL GAMES’ separate WAX/XRPL records](https://graffitikings.com/pages/charlie-buster-no-ball-games-nbg.html), and the [Charlie Buster source network](https://graffitikings.com/pages/charlie-buster-source-network.html). These references are complementary, not independent certification of artist claims, token balances, or story-lore events.

The reciprocal-link PR adds 22 contextual destinations across nine published pages. `npm run audit:reciprocal` checks their exact route paths and duplicate placements against a fixed allowlist derived from the Graffiti Kings sitemap. It does **not** make live HTTP requests or claim Google indexing. The normal `npm run build` still runs the internal link and metadata audit, and the existing PR validation workflow runs both checks. If GK renames or removes a page, review both sites and update the allowlist deliberately.
