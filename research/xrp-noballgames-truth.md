## 9. Token and chain truth layer

### 9.1 XRPL technical context

The XRP Ledger supports fungible tokens and non-fungible tokens. Tokens can be issued on XRPL using standards such as trust line tokens, and XRPL documentation describes trust line tokens as using a bidirectional trust model where token balances are tracked in on-chain trust lines. XRPL also has a long-running decentralized exchange where users can trade XRP and issued tokens through offers/order books.

For project content, the critical rule is:

> A token symbol alone is not enough proof of identity on XRPL. Issuer identity matters.

This matters because anyone can issue a token using a familiar ticker. Public pages must not tell people that a ticker is official unless the official issuer is clearly shown.
